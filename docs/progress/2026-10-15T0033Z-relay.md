## A note on test cost vs. the mutation gate

The committed RSS-at-cap test (item 9) initially ran at the production 256 MiB default,
costing 34s on its own and pushing the whole test file from a 12.5s baseline to 47s. The
mutation gate runs the whole file once per surviving-candidate mutant (171 of them here),

past the `mutation-gate` CI job's own 90-minute budget. Cut to 32 MiB (still 32x the
existing round-2 test's 1 MiB toy cap, and confirmed separately to measure the same ratio
as 256 MiB) before the first real mutation-gate run; file runtime is 17.1s. Worth recording
for whoever picks up a similarly "measure at real scale" item next: build the test's own
cost into the choice of scale, not just correctness.
