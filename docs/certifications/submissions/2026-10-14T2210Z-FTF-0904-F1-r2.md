## Why this design (reviewed, not just accepted)

Rather than enumerate every pairwise stem compound as a regex alternation (the approach this
reviewing session had independently built before finding this PR), the implementing session
split each candidate key on `_`/`-`/`.`/camelCase boundaries and checks only whether the **last
word** is in a 15-name set (`_QUERY_PARAM_NAMES`). This covers every `*_key`/`*Key`, `*_code`,
`*_verifier` compound generically, with no combinatorial alternative list and no position-anchor
character class at all — `_QUERY_ASSIGN` just finds every `key=` shaped run
(`(?<![\w.\-])[\w.\-]++=`), and a Python-level name check decides whether to redact. This sidesteps
two real problems this reviewer's own alternative design had: (a) a ~380-alternative regex tried
at every occurrence of `(`/whitespace (now trigger characters) measurably slowed four pre-existing
`_PAIR` adversarial timing shapes; this design's single linear scan plus O(1) set lookups has no
such blowup; (b) explicit position enumeration (`line-start`/`after-quote`/`after-space`/...)
needs a new named case per discovered position — this design needs none, since *any* `key=` is
a candidate regardless of what precedes it.

## One real defect found and fixed during this review

`qp-camel-run`'s shape, `"aB" * (size // 2) + "="`, is `size + 1` characters at every sweep size
(the trailing `=` was not accounted for) — harmless at 8 KB/64 KB, but at the top 262144-char
tier it is one character over `MAX_TEXT_LENGTH`, so `redact_text` raised `LogRedactionError`
(fail-closed, correct) instead of ever exercising the camelCase scan at the real top size. The
suite's own `_timed_redact` child catches `LogRedactionError` and still reports a valid elapsed
time, so the timing check "passed" while silently measuring the fail-closed path, not the shape.
Fixed to `("aB" * (size // 2))[: size - 1] + "="` (exactly `size` chars); re-measured directly at
all three sweep sizes (8192/65536/262144): 0.004s / 0.031s / 0.135s, comfortably under the 4s
limit and now actually exercising the real scan at the real top size.
