## Design

`NumericSpec(expected, unit, abs_tol, rel_tol, max_decimals)`: all five required, none defaulted. Pass when the
deviation is at most `max(abs_tol, rel_tol * |expected|)` (isclose meaning), `rel_tol < 1`. Exact arithmetic with
`fractions.Fraction`, so no float rounding at a boundary. The candidate value is a decimal string (strict grammar,
at most 64 chars); the unit is compared exactly. Issue codes: `missing_value`, `not_finite`, `malformed_number`,
`not_a_decimal_string`, `missing_unit`, `wrong_unit`, `too_many_decimals`, `out_of_tolerance`, reported together,
sorted. A malformed spec or record type raises `NumericGraderError`.
