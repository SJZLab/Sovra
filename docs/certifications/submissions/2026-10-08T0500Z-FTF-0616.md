## What changed (workers/evaluation/llm_judge_grader.py)
1. **§27 critical:** `critical=True` raises `LlmJudgeCriticalNotAllowedError` before any network call.
   The `deterministic_corroboration` argument and `LlmJudgeCriticalRequiresCorroborationError` are
   removed. The test asserting critical + corroboration=False gives PASSED is deleted; the new test
   asserts the refusal, zero requests, and that the same call with critical=False reaches the gateway.
2. **Calibration (§69.5):** `CalibrationRecord` binds `rubric_id`, `rubric_version`, `judge_model_id`,
   two distinct reviewer ids and a judge-vs-adjudicated 2x2 matrix. `meets_thresholds`: n >= 100,
   agreement >= 90%, Cohen's kappa >= 0.70 (exact integers; undefined kappa is refused).
   `is_calibrated_for` is an exact (case-sensitive, unpadded) triple match.
3. **Criterion scores:** `JudgeRubric.criteria` (unique, non-blank ids). The strict `json_schema`
   requires `criterion_scores` with exactly those ids; each score and `confidence` in [0, 1].
   Results carry scores in rubric order.
4. **Identity:** `LlmJudgeResult` records `rubric_id`, `rubric_version`, `requested_judge_model_id`,
   `resolved_model`. A resolved model outside `approved_judge_model_ids`, or equal to the candidate, is
   `MODEL_MISMATCH` (never a verdict; wins over unparseable content).
5. **Strict JSON:** `_strict_json_loads` rejects duplicate keys, NaN/Infinity, numbers overflowing to
   infinity, and turns `RecursionError` into a refusal; used for the envelope, the rejection body and
   the content. Truncated JSON is never repaired. Exactly one choice is accepted.
6. **Tests added:** case-variant/padded judge id vs approved set; a 400 is sent once; 201/202/203/206/204
   are not verdicts; expired, access-denied, unreachable and malformed secret refs never reach the gateway;
   two choices refused (all orderings); unhashable / wrongly typed verdict values are SCHEMA_VIOLATION.
7. **spec-matrix:** FTF-0616 set to IMPLEMENTED / L1-PROVEN / PROVISIONAL with `proving_test`; the
   real-judge clause recorded as BLOCKED_EXTERNAL (owner action: gateway key + approved judge).

Test-fixture fix (not production): the local test CA now carries `basicConstraints`/`keyUsage`, which
Python 3.13 requires; CI's 3.12 accepts either.
