## Return items
1. **INVALID-ENCODING-LOCATOR** — fixed. The importer now parses text itself and reports the physical
   line of the first bad byte; the text before the bad byte is parsed first, so an earlier structure
   error wins. Tests: every chunking 1..13, 64 and whole for five encodings, bad bytes after a
   multiline CRLF record, a truncated tail, structure error before bad bytes.
2. **FIELD-LIMIT-GLOBAL-RACE** — fixed. No `csv` module, so no `csv.field_size_limit` read or write.
   Test: 8 threads with mixed limits x 15 imports all complete and the global is unchanged.
3. **WIDE-RECORD-MEMORY-UNBOUNDED** — fixed. One logical record is capped at `2*max_record_bytes+2`
   characters across physical lines, a field at `max_record_bytes`; both fatal `field_too_large`
   at exactly the first character over, identical for every chunking. tracemalloc test: a 64 MiB
   single record is refused with peak < 24 MiB and under 8 MiB read.
4. **CONTENT-TYPE-GATE-MISSING** — fixed. `verified_content_type` is required; only exact `text/csv`
   is imported. The other four `SUPPORTED_CONTENT_TYPES` and eight malformed values (None, "", case,
   whitespace, parameters, bytes, int, str subclass) give `failed` / `content_type_not_supported_by_importer`
   with `bytes_read == 0` and not one chunk requested. Preview takes the same gate.
5. **Evidence** — `tests/integration/test_ftf_0504_csv_import_postgres_s3.py` and CI job
   `csv-import-integration` (in `ci-verdict` needs; green on PR #775): CSV uploaded through the real
   FTF-0501 routes, streamed by `open_dataset_source` as `sovra_app`, Arabic/leading-zero/formula/CRLF
   multiline preserved for two chunkings, report hash == `Dataset.verified_sha256`; JSONL dataset
   refused with no storage call; foreign/missing/hidden held-out identical `DatasetNotFoundError`,
   held-out readable with `include_held_out=True`; truncated object and a mid-stream S3 stop are
   `blocked/source_unavailable`; invalid stored bytes `invalid_encoding`; planted markers absent from
   reports, locators and log records. Generated tables replace hand-written ones: a 3,000-case
   differential of the parser against `csv.reader` (strict) at five chunkings, over delimiters `, ; TAB |`.
