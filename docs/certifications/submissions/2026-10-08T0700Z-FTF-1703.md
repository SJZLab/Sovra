# FTF-1703 Training dataset — submission (PROVISIONAL / L1-PROVEN, not certified)

Branch `relay/FTF-1703-r1`. Files: `evals/reference/training_dataset.py`, `tests/reference/test_ftf_1703.py`,
CI step in `.github/workflows/ci.yml` (additive), `docs/spec-matrix.yaml` FTF-1703 entry.

## What is real
- 1,200 synthetic traces (7 kinds; lookup, note, note_retry, approval_approved, approval_denied, cross_subject,
  execute_pending; the last three are critical), one independent group + unique entity per trace.
- Every tool result comes from a real FTF-1702 `ToolEnvironment` (real authorization, idempotency, approval state
  machine). `verify_trace_replay` re-executes each trace and refuses forged results / outcomes / final answers.
- Dataset hash deterministic (also under PYTHONHASHSEED 0 and 777).

## Disclosed, not hidden
Acceptance says "reviewed". The generator cannot approve its own output: a trace counts only with an independent
`ReviewDecision`. With no reviews: approved 0, `meets_floor` False, status `BLOCKED_EXTERNAL_independent_review`.
The independent human review (Argilla) is the open external step; nothing here fakes it.
