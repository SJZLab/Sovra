## Point by point

1. **B64-RUN-LENGTH-CAP-CLASS** and 2. **HEX-RUN-LENGTH-CAP-CLASS**:
   `test_long_base64_and_hex_runs_are_one_whole_match_and_dense_sweeps_find_every_secret` pins
   the class in two ways.
   - **One whole match.** A single base64 run of 1,066,668 chars, and a single hex run of
     1,200,000 chars, must each come back from `_BASE64_RUN` / `_HEX_RUN` as exactly ONE match
     spanning the whole run. A length cap of any size below 1 MB therefore fails the test,
     anchored or not.
   - **Dense sweep.** A secret is placed every 40 bytes across one ~20 KB base64 run and one
     ~30 KB hex run (375 placements each). The step is finer than the secret's encoded length.
     Every placement must be found, so no window or cap inside a run can hide one.
