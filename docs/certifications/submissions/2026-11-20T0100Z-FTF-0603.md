## What it does
GET suite, GET every case page (bounded: repeated cursor, runaway pages and duplicate case_key are errors),
reviewer-declared sample plan (required critical categories, min total/critical/per-category; a final suite
starts from the 1000/100 reference floors), pure `validateSuite`, `computeSuiteSha256` (SHA-256, FIPS 180-4,
no new dependency, over suite identity + every case in case_key order), Lock → inline permanent-action
confirmation → handler reloads, re-validates, compares the hash, then POSTs the real `/lock` route. A lock
reply counts only for the same suite id with `status: "locked"` and `locked_at` set (Law 17).
