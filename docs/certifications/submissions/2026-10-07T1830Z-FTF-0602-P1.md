## Decisions made where the QUEUE entry was silent (default-resolution rule)
- Field names are the Section 6.14 entity names (`input_json`, `expected_json`, `grader_config_json`).
- `group_key` is required and never defaulted: Section 69.2 says repeated turns and template near-duplicates are not independent, so defaulting each case to its own group would inflate effective n by omission. `weight` defaults to 1, `critical` to false, `grader_config_json` to `{}`.
- Whitespace-padded `case_key`/`category`/`language`/`group_key` are refused (identity is exact); NUL, lone surrogates, depth > 64 and non-finite numbers are 400s, not database errors.
- Body cap 32 MiB (declared length refused before `require_role`'s own body read; streamed cap as well). A 500-row batch therefore fits only if the rows are small; each payload keeps its 2 MiB bound.
- The app-side size bound is measured with Postgres's jsonb text form (", " and ": "), so it is never looser than the database CHECK.
