## Control-plane ruling applied
Capture is now an allow-list, not a content-key deny-list:
- a top-level key in `GENERATION_SETTINGS_KEYS` is kept verbatim (independent typed copy);
- a key in `CONTENT_KEYS` is never read, not even as a digest;
- any other key is held as `ContentDigest(sha256 of a canonical, type-tagged form)`, so a bridge that adds, drops or rewrites it is still a visible difference without the value being captured;
- `extra_body` gets the same treatment one level down (`EXTRA_BODY_SETTINGS_KEYS`), with content-named children dropped.
The deny-list's recursive scrub is gone: key names inside a kept value are never inspected. The module docstring no longer claims capture works on a "full request body".
