## What it does
`emit_event(kind, fields)` validates a workflow/log/span event against that kind's frozen, closed
field schema (`EVENT_SCHEMAS`) and returns an immutable `TelemetryEvent`. Every field kind
(`id`/`code`/`enum`/`count`/`number`/`timestamp`/`bool`/`content_ref`) is a short, bounded shape;
there is no free-text field anywhere. `ContentRef` is an opaque two-id pointer to encrypted content
kept elsewhere (Section 11.4/12), never inline content.
