Note on the Start over gate (fault G1). The earlier code carried `disabled={checkingStatus}`; that fault
was GREEN because nothing asserted it. `Button` treats a non-empty `disabledReason` as disabled, so
keeping both props would make `disabled` redundant and its removal permanently GREEN. The gate is
therefore the single prop `disabledReason={checkingStatus ? … : undefined}`, and the fault is "that
prop removed" (which is exactly "the finalize-section Start over is no longer disabled while checking").
