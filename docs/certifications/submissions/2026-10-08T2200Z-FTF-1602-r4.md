## Fix (QUEUE item 0i)

Record-pin race: `_load_record` reads `get_version(record_key, pinned_version_id)`, never `get_latest`, then re-lists and requires the same single, latest, non-delete-marker version id ("backup record changed while it was being read"). 2. `create_backup` refuses an existing backup_id before writing a blob, and confirms after the write that the new record is the key's only version (version id compared exactly).
3. `verify_backup`/`restore_backup` require a tz-aware `datetime` `now` and raise `ObjectStorageBackupError` (naive or non-datetime).
4. spec-matrix notes and evidence_hash updated.
