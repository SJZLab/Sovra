## Return items (0k)
1. **MIDSTREAM-CRASH** — fixed. Every line goes through P1 `strict_loads`: a 4301-digit int is
   `number_out_of_range`, a 100,000-deep array/object is `nesting_too_deep`; later lines still import.
2. **Silent acceptance** — fixed: duplicate key at every level, NaN/±Infinity/±1e999, lone surrogate escapes
   → `duplicate_key` / `non_finite_number` / `invalid_unicode`.
3. **META-LEAK** — fixed: rejections are `RowRejection(locator, code, slot)` only; no FTF-0506 text, no byte values.
4. **Law 17** — fixed: a source exception is `blocked`/`source_unavailable`, a changed source `failed`/`source_changed`,
   plus `parse_timeout` and `too_many_rejections`; always an `ImportReport`, never `completed`.
5. **Bounded memory** — fixed: input is chunks. The line buffer holds at most `max_record_bytes+1` bytes; an oversize
   line is discarded as it arrives. 64 MiB line: peak < 8 MiB, followers import. Peak does not grow with record count.
6. **Contract signature** — `import_jsonl(chunks, *, mapping, expected_sha256, expected_size, verified_content_type,
   dataset_purpose, source_type, limits, tool_schemas, tool_argument_validator)` plus `run_jsonl_import` /
   `jsonl_events`; content-type gate (only `application/jsonl`, `application/x-ndjson`), mapping → FTF-0508 candidate,
   deterministic `record_id`.
7. **Line rules** — BOM only at byte 0; UTF-16/32 (BOM or NUL pattern) fatal `unsupported_encoding` at `line:1`;
   exactly one trailing CR stripped; blank lines in `blank_lines`.
8. **Evidence** — generated tables (invalid-UTF-8 class × position × chunking, line endings × chunking, BOM, size
   max−1/max/max+1 × CR/CRLF × chunking, depth, duplicate-at-depth, numbers, non-objects, trailing garbage, Unicode
   content, 200-case differential vs `json.loads`); PG16 + SeaweedFS test through the real FTF-0501 routes in CI job
   `jsonl-import-integration` (in `ci-verdict` needs); mutation 0 survivors.

## Disclosed
- Locator is `line:<n>` (physical, blank lines counted); `record_index` is the non-blank ordinal.
- `source_schema_sha256` is `None` (a JSONL source has no header).
- A line that is only ASCII whitespace (incl. VT/FF) is blank; Unicode whitespace is not (→ `invalid_json`).
- No live route calls the importer yet: `proving_symbol` stays blank; product-true stays 47/47.
