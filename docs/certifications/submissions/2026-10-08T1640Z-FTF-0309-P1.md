## Disclosed gaps
- **No probe store exists.** The DoD says to use the latest FTF-0212 probe "the catalog already holds"; nothing in the repository persists a probe result (the probe route returns it and forgets it). The route takes an optional `probe_lookup` seam and passes None when absent, so `inference_only` is unreachable on the live path until a probe store exists. The classifier-level rule (a probe for another model or an unverified route identity is ignored) is proven through the seam.
- A cross-organization artifact object reaching the classifier is mapped to the same 404 as a missing one.
- A discovery state other than `discovered` is 503 `gateway_unavailable` (Law 17), consistent with the FTF-0308-P1 POST.
- The FTF-0205 enrichment call is a second outbound request to the gateway; the "at most once" DoD is read as discovery (`discover_models`), which the counting test pins.
