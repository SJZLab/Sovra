Upgrade first reads for violating rows and raises `ArtifactReadyWithoutLicenseError` naming the ids; it never rewrites or deletes data. Downgrade drops only the CHECK. Revision id is 32 chars (my first draft was 33 and my own shape test caught it).
3. **Trainability** (`training_capability_classifier.py`): `trainable_open_weight` requires `license_approved`. The capabilities route derives `trainable` from the capability enum, so it follows.
