## What this round changes (production)

| File | Change |
|---|---|
| `apps/web/components/ui/errors.ts` (new) | One shared `networkError(caught, locale, {write})` plus `UiError`/`RecoveryKind`/`kindForStatus`. ## Recorded decisions (severity 2, not done — each with its reason)

* **D1 `Field` for the 1301 inputs (return point 8).** Not adopted: `Field` puts a
  required/optional marker inside the `<label>`, and the certified `ftf_1301.spec.ts` asserts the
  exact label text (`label[for="cost-profile-type"].textContent === "النوع"`). Changing the label
  text would change a certified assertion. The inputs instead carry the same `--target-min` block
  size as the selects (`R3-8`). Control plane may rule that a contract change is wanted.
* **D2 `ErrorSummary` on a failed submit.** Not added: the create route returns one request-level
  `detail`, never per-field errors, so there is nothing to link; native `required` covers empty
  fields. The request-level error is announced and has a recovery step.
* **D3 `StatusBadge` for raw status enums.** Not adopted: its vocabulary is the fixed §72.2 state
  set, which has no "callable / stale / removed / unverified / expired" members; mapping them
  would invent states. They stay the server's own words in `<bdi>` (certified tests assert the
  literals).
* **D4 server `detail` codes under `ar`.** An unrecognized server `detail` is shown verbatim
  (data, in `<bdi>`); the certified `UX05 round 2: an unrecognized … is data` tests assert it.
  Known codes are translated.
* **D5 cancellable long loads.** `Pending`'s `onCancel` is not wired: these loads use plain
  `fetch` with no `AbortController`. The NN/g 10-second cancel is not provided; recorded as a
  severity-2 finding (F3 below) for Control plane to rule on.
* **D7 confirm dialogs are non-modal.** Tab leaves the inline `alertdialog` (no `aria-modal`, no
  focus containment); Escape cancels, focus enters on open and returns on cancel/confirm.
  Severity 2, recorded.
* **D8 raw enum literals under `ar`** (`per_input_token`, `callable`, `inference_only`) and the 0309
  blocker sentences that embed them without `<bdi>`: same decision as D3/D4, severity 2; the
  certified tests assert the literals.
* **D6 `ErrorBoundary`.** Not added: no page shell mounts these components yet (FTF-H029); round 2
  verified that no malformed item shape unmounts a component, and the browser matrix asserts no
  uncaught exception or unhandled rejection in any state.
