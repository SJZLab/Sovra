| Negative: final answers unavailable to training roles | listing never renders `expected_json`; `final_suite_content_restricted` 403 on list, import or save clears every case and closes the editor |
| Law 17 | 409 `duplicate_case_key`/`suite_locked`, network failure, malformed 201/200 bodies are errors; listed cases unchanged after a failed save |
| Range / contract | 0, 501, bad JSON, bad JSONL line, non-object row send nothing; exactly 500 accepted; cursor encoded; Load more appends; credentials on every request; URL helpers |
