## Design

Per-parameter specs from a closed set: `Identity`, `Exact`, `OneOf`, `NumberWithin(expected, abs_tol)`, `OfType`.
`allow_extra` is a required keyword (no default). Equality is strictly typed (`type(a) is type(b)`, recursive), so
`"5"`≠`5`, `5`≠`5.0`, `true`≠`1`. A tolerance applies only to a real finite JSON number. Each identity is compared
with its own expected value; a wrong value equal to another declared identity's expected value is reported as
`swapped_identity`. Issues are a sorted tuple of (parameter, keyword, message), content-free.
