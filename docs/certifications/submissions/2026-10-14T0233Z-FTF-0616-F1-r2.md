## What the return asked for (four items)

1. The "golden" request-byte test was self-referential (asserted against its own captured constant, not an
   independent value). **Fixed:** `_ROUND8_BODY` is now the literal certified round-8 request body (captured
   from the pre-F1 module, parent of commit `45c8de7`), and the test asserts the live request equals that fixed
   byte string plus exactly the appended `, "cache": {"no-cache": true}` -- and, independently, that stripping
   that one suffix reproduces the round-8 bytes exactly. `test_the_request_bytes_are_round_8_plus_only_the_cache_field`.
2. Value-normaliser coverage was a hand-picked list. **Fixed:** `test_every_code_point_at_every_position_in_a_value_is_none_or_verbatim`
   sweeps **every one of the 1,114,112 Unicode code points** (`range(0x110000)`) at leading/inner/trailing position
   in the header value (3,342,336 direct calls total), asserting the oracle (printable ASCII 0x20..0x7E verbatim,
   everything else `None`) unconditionally -- not sampled, no `FULL_SWEEP` gate on this one, since it is a pure
   function call with no network cost. `test_a_value_is_never_normalised_or_stripped` adds the named look-alikes
   (NBSP, U+00AA, fullwidth, ligature, trailing C1 controls). `test_look_alike_and_unsafe_values_on_the_wire` covers
   the same question over a real HTTP response (wire-level, Latin-1 + C0/C1 controls a header line can actually
   carry): sampled 1-in-6 by default (26 codes), **all 157** under `FTF_0616_FULL_SWEEP=1` (measured this round,
   see below).
3. Name-normaliser coverage was likewise hand-picked. **Fixed:**
   `test_header_name_variants_are_ignored_unless_an_ascii_case_variant` generates the pool itself
   (`_name_code_points`): every Cc/Cf/Zs/Zl/Zp category code point, every code point <= 0xFF, and every code point
   whose NFKC/NFKD normalisation or case-folding touches a character in the real header name -- **1,030 code
   points measured this round** (the test's own assertion is `len(pool) > 900`) -- substituted and inserted at
   every one of the header name's 18 positions, plus as a leading/trailing affix: `(1,030 x 18 x 2) + (1,030 x 2)
   = 39,140` direct calls, asserting `None` everywhere except a pure-ASCII case variant of the real name.
4. The submission claimed "whole changed file" mutation coverage but CI's diff-mode gate only mutated functions
   in round-1's actual diff (133 mutants), and no `FTF_0616_FULL_SWEEP=1` run was ever recorded. **Fixed:** both
   measured this round (full account below).

New fault rows added to `FAULTS` (round 2): F1-V value-stripped, F1-V value-NFKC-normalised, F1-N name-stripped,
F1-N name-NFKC-casefolded, F1-N name-drops-Cf, F1-R1 max_tokens drifts, F1-R1 ensure_ascii flips, F1-R1 stream
flips -- 8 new rows, each confirmed RED by `test_zz_self_attack_each_fault_turns_this_file_red` (unchanged
mechanism: the real module on disk is mutated, this file is re-run in a fresh child process, and the original
bytes are restored).
