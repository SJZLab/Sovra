## E (write)

**`packages/integrations/argilla/client.py`** (new, pure, stdlib-only). `ArgillaClient`:
`get_status`, `list_workspaces_me`, `create_workspace`, `ensure_workspace` (idempotent: find by
name, create if absent, resolve a create-race via one re-list rather than a retry loop),
`list_workspace_users`, `add_workspace_user`, `remove_workspace_user`, `create_user`, `get_user`,
`delete_user`. Four error classes kept apart so a caller can never turn one outcome into another
(Law 17): `ArgillaUnavailableError` (network/timeout/5xx -- retryable, never success),
`ArgillaRejectedError` (understood-and-refused, or a malformed/duplicate-key/non-finite/
wrong-shape response -- never retried as-is), `ArgillaNotFoundError` (404),
`ArgillaConflictError` (409, the outcome `ensure_workspace`/a future `create_user` caller
branches on for idempotent provisioning). Every identifier-shaped input (username, workspace
name, role, password length, UUID text) is validated *before* any request is built, so a bad
caller input never reaches the wire. The caller's own API key is redacted out of every raised
error message and refused outright (before any header is built) if it contains a control
character (the same CRLF-header-injection defense the MLflow client uses for its bearer token).

**`tests/tasks/test_ftf_r006_p1_client.py`** (new, no-network, loopback HTTP stub scripted to the
verified real response shapes -- see the fault -> RED table below).
